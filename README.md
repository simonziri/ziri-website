# ZIRI Website 2026

Next.js implementation of the ZIRI Website 2026 Figma design.

## Current scope

- Shared design tokens and TT Hoves Pro typography
- Responsive site header
- Figma-matched opening hero section and client logo strip

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run typecheck
npm run build
```
